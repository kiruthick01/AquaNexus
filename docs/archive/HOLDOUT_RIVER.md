# The Naka (中川) — a river the model has never seen

Generated by `scripts/holdout_river.py`.

Every generalisation claim in this project until now was *within* the Ayase: four stations, held out one at a time, sharing a channel and a catchment. This applies the shipped model, unchanged, to a different river — 192 observations across 5 stations, reserved as a holdout during the data audit and never used until now.

## Verdict

Pooled over the whole river the Ayase model scores R² -0.081 — worse than predicting that river's own mean, which needs no model at all.

**That single number is misleading, and the split says why.** Where the model has evidence it scores R² +0.336 — against +0.394 on its own river, so it transfers to a different catchment nearly intact. Where it does not, it scores -0.903. The pooled figure is the average of a model working and the same model extrapolating, and 63 of 192 observations are outside the range it was fitted on.

The API already flags exactly these rows as out of range on every prediction. This is what that flag is worth: on the wrong side of it the model is worse than useless, and on the right side it is about as good as it is at home.

A model of the same specification fitted to this river reaches R² +0.483 — better than the Ayase model manages on the Ayase. The Naka is the more predictable river, so the gap between -0.081 and +0.483 is the cost of transfer rather than a hard river.

The transfer is **biased -1.29 mg/L**, and the direction was predicted before the run: the Naka carries 8.0–8.8 mg/L against the Ayase's 6.9, so a model fitted to the more polluted river reads the cleaner one as worse than it is. A model that learned this river's oxygen level rather than its physics would do exactly this.
